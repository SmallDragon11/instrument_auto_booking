# 已確認的需求決策

| # | 議題 | 決策 |
|---|---|---|
| 1 | 下週的工作表尚未建立 | 直接回報失敗，不自動建立工作表 |
| 2 | 時段衝突 | 使用者指定的一段連續時段只要有任一格已被佔用，整段跳過，改試下一個優先序的選項；全部處理完後向使用者回報預約結果 |
| 3 | 溫度 | 暫不填寫 |
| 4 | Google 授權 | 使用者以個人 Google 帳號 OAuth 登入（不使用服務帳戶） |
| 5 | 設定頁 | 使用者人名、預約填寫時間（預設每週五 13:00）在 App 的 Setting 頁設定 |

| 7 | 使用者 | 實際使用者不是開發者，App 必須能直接雙擊執行，設定一次後即可使用 |
