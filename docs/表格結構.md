# 儀器預約試算表結構

> 分析來源：`tube furnace reservation table.xlsx`（2020-10 ～ 2026-10，共 151 個工作表）
> 分析日期：2026-10-05

## 1. 工作表分類

| 類型 | 名稱格式 | 範例 | 用途 |
|---|---|---|---|
| 管型爐 | `YYYYMM` | `202610` | A-牆 / B-窗 / C-小房間 |
| 烘箱 | `M月ovenYYYY` | `10月oven2026`、`9月oven2026` | ovenA / ovenB |
| 其他 | — | `Sheet13`、`工作表5`、`oven`、`oven blank`、`6月oven`（2022 以前無年份） | **必須排除** |

- 月份**不補零**（`9月oven2026`，不是 `09月oven2026`）。
- 名稱可能有多餘空白（例：`'1月oven2023 '`），比對前要 `strip()`。
- 2022-06 以前的烘箱表名稱沒有年份（`6月oven`）。

## 2. 工作表是「按週」切分，不是按日曆月

每個工作表包含 4～5 個完整的週（週一～週日）。跨月的那一週歸屬於**週一所在的月份**。

例：10/1（四）～10/4（日）位於 `202609` 的最後一週（9/28 起），而非 `202610`。

**→ 程式必須「以日期搜尋所在工作表」，不能從日期推算工作表名稱。**

> 註：2025-06 以前的舊表是日曆月制（月初/月底不屬於本月的日期留空）。只要以日期搜尋即可兩者通用。

## 3. YYYYMM（管型爐）工作表

```
     A           B     C     D     E     F     G   ...   T     U     V
1    (標語)      每週五13:00開放預約下週管型爐&烘箱，偷跑延畢!
2    °C          H2    O2    Ar    vac   air   MILA  Ar/H2 CO2/H2 N2      ← 氣體圖例（儲存格底色＝氣體顏色）
3    tube        A     B     C     A     B     C   ...   A     B     C     ← 子欄標頭（不可靠，見 §6）
4                Mon               Tue              ...  Sun
5                [10/5  合併 B5:D5] [10/6 合併 E5:G5] ... [10/11 合併 T5:V5]  ← 日期列
6    0900~1000   ...
...
20   2300~       ...
21               [10/12 ...]                                               ← 下一週日期列
```

- **每天 3 欄**：日期儲存格合併 3 欄，依序為 A-牆、B-窗、C-小房間。
- **每週區塊 16 列**：1 列日期 + 15 列時段（目前的規律，但不可依賴，見 §6）。
- **時段**：A 欄文字 `0900~1000`、`1000~1100`、…、`2200~2300`、`2300~`，1 小時一格，涵蓋 09:00–24:00。
- **凍結窗格**：`B5`。

### 氣體圖例（第 2 列）

從 `B2` 往右讀到第一個空白儲存格為止，值＝氣體名稱、底色＝氣體顏色。目前（2026-10）：

| 氣體 | 顏色 |
|---|---|
| H2 | `F4CCCC` |
| O2 | `B6D7A8` |
| Ar | `A4C2F4` |
| vac | `FFE599` |
| air | `B4A7D6` |
| MILA | `999999` |
| Ar/H2 | `DD7E6B` |
| CO2/H2 | `76A5AF` |
| N2 | `D5A6BD` |

圖例歷年有變動，**必須每次從目標工作表讀取，不可寫死**：
- Ar/H2：`00FFFF` → `DD7E6B`（2025-03 起）
- 新增項目：Ar/H2（2022-10）、CO2/H2（2022-12）、N2（2024-06）
- `202112`～`202201` 的 O2 顏色為 `93C47D`（其他月份為 `B6D7A8`）
- 2021 年的表在圖例後面接著人名（無底色），讀到無底色儲存格也應停止。

## 4. MM月ovenYYYY（烘箱）工作表

```
     A           B     C     D     E    ...   N     O     P        Q
1    (空白)      A     B     A     B    ...   A     B     (標語，合併 P1:S1)
2                Mon         Tue        ...   Sun         ovenA    ovenB   ← 圖例
3                [10/5 合併 B3:C3] [10/6 合併 D3:E3] ... [10/11 合併 N3:O3]  ← 日期列
4    0900~1000   ...
...
18   2300~
19               [10/12 ...]
```

- **每天 2 欄**：日期儲存格合併 2 欄，依序為 ovenA、ovenB。
- **顏色依欄位固定**：ovenA＝`FFE599`（黃）、ovenB＝`A4C2F4`（藍）。
  - 可參考 `B1`/`C1`、`P2`/`Q2`、`P8`/`Q8`（2024-07 起一致）。
  - 2024-07 以前的舊表 `B1`/`C1` 無標頭、更早的表 `P2`/`Q2` 也沒有圖例 → 只能依位置判斷。
- 星期列（Mon…Sun）只出現在第一週上方（第 2 列），之後的週只有日期列。
- 時段同管型爐（15 格，`0900~1000` ～ `2300~`）。
- **凍結窗格**：`B3`（舊表為 `A3`）。

## 5. 預約的表示方式

- 一段預約＝同一子欄中**連續塗色**的儲存格，**第一格填人名**。
- 同色連續區塊中若出現新的人名，代表另一筆預約從該格開始。
- 預約範圍內的數字是溫度（°C），例：`70`、`300`、`600`（本程式暫不填寫溫度）。
- 也有人用直書文字佔位（例：一格一段寫 `d`/`a`/`t`/`a`/`re`/`qu`/`ired`）。

### 空格 vs. 已佔用

| 狀態 | 判斷條件 |
|---|---|
| 空格 | 無值，且底色為「無填色」、`FFFFFFFF`（白）或主題色 0（白） |
| 已佔用 | 有任何值，**或**底色不屬於上列白色 |

實際使用的顏色**不一定等於圖例**：常見 `FDE49A`（近似 vac）、`D9D9D9`/`CCCCCC`（灰）、`EAD1DC`、`9FC5E8` 等。因此判斷佔用不能只比對圖例色。

## 6. 定位規則（已對全部歷史工作表驗證）

**不可寫死列號、欄號或工作表名稱。** 定位流程：

1. 取得儲存格**計算後的值**（日期多為公式，例 `=T5+1`、`=B21+7`；openpyxl 需 `data_only=True`，Google Sheets API 預設即回傳計算值）。
2. 依名稱格式篩選出同類型工作表，掃描所有值為日期的儲存格，找出目標日期所在的工作表與儲存格。
3. 由該日期儲存格的**合併範圍**取得欄位；子欄依**合併範圍內的第幾欄**決定（管型爐第 0/1/2 欄＝A/B/C；烘箱第 0/1 欄＝ovenA/ovenB）。
4. 由日期列往下，以 **A 欄的時段文字**辨識時段列，直到下一個日期列為止；不是時段文字的列要跳過。

### 已知的例外（規則必須能容忍）

| 工作表 | 狀況 | 為何不能用簡單規則 |
|---|---|---|
| `202609` | 第 84 列是誤插入的列（A 欄無時段文字，但有塗色） | 不能用「日期列 + N」推算時段列 |
| `202511` | `H3` 的 `A` 標頭被刪除 | 不能讀第 3 列標頭判斷子欄 |
| `202209` | 部分 `B` 標頭為空字串 | 同上 |
| `202210`～`202302` | 週五後多一欄「反應器」，週五日期合併 4 欄 | 子欄只取合併範圍的前 3 欄 |
| 2024-07 以前的烘箱表 | 第 1 列無 A/B 標頭 | 只能依位置判斷 ovenA/ovenB |
| 2021-07 `7月oven` | 日期列從第 4 列開始（其他為第 3 列） | 不能寫死第一個日期列 |

驗證結果：2023-03 以後的所有工作表完全符合上述規則；更早的表在套用「合併範圍內第幾欄」後亦可正確定位。
